# 证据目录说明

本目录保存对应历史代码快照的日志、测试结果和设备观察。证据仍应保留，但只能证明其记录时的文件指纹、构建和运行环境，不能自动证明当前工作区。

U11 的历史真机结论与材料边界见 [`../19-现行结论与历史材料边界.md`](../19-现行结论与历史材料边界.md)，Mac 隐私链原始证据见 [`../21-Mac隐私生命周期与剪贴板系统核对.md`](../21-Mac隐私生命周期与剪贴板系统核对.md)，当前整体架构和最新证据索引只认 [`../22 §8`](../22-密码与身份验证整体架构审计与加固.md#8-验证记录)。后续代码发生变化时必须重新验证，不能复用旧结果冒充新通过。

最新快照的测试数、固定结果包、构建身份和设备观察只由 [`../22 §8`](../22-密码与身份验证整体架构审计与加固.md#8-验证记录) 维护，本目录不复制第二份台账。本目录及外部日志不得记录应用密码、备份口令、密钥明文或生物识别内容。
