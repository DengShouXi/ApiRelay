# v1.13.11 购买权益最终计划

阶段：3；日期：2026-09-24；分支：`v1.13.11`；起始 HEAD：`8e6c22109b9f5851dacb31b96e8915d855b0e0f3`。输入：本包 00C、00D、01–03，现行 Stage 1 FR-026–029/FR-062，Apple StoreKit 文档及当前代码。授权：用户明确要求单 AI 在本独立分支连续完成计划，不再逐阶段提示；仅覆盖购买权益，不授权 `v1`、`main`、tag、Archive、TestFlight、App 审核或 `v1.14` 同步。

## 决定与不变量

1. 保留 StoreKit 2 的已验证交易为唯一付费授权事实；本机 `EntitlementSnapshot` 只供观测，不得在缺少有效交易时放行。免费上限仍为 3；退款后超额旧密钥只读保留。产品 ID、家庭共享和商店配置不变。
2. UI 将权益核对明确分成核对中、免费、已购、暂不可核对。未确认免费时不展示可执行购买动作；查询失败给重试/恢复入口，不声称用户未购。商品加载与权益核对分离。请求采用代次，旧响应不得覆盖较新结果；前台返回必须复核。
3. 额度的 `nil` 仅表示无限，不再兼作错误；显示层有独立的未知/不可核对状态，业务写入仍由 KeyVaultService 最终检查。
4. `pending`、取消、失败和恢复结果分别表达；未验签、退款或错误不得授予权益。购买成功后第 4 把的时序风险先用 StoreKit 本地交易测试验证；只有证实后才允许受已验证交易约束的最小衔接，不引入永久缓存授权。
5. 真机 Sandbox/跨设备/退款是独立于 Xcode 本地 StoreKit 的验收项。无法取得设备或测试账号时如实保留发布阻塞，不用模拟器代替。

## 执行波次

- A · 先增加可控 UI fixture 与状态/业务回归测试，再修设置页、付费墙和额度未知态；中英本地化同时核对。每波运行定向测试和 `git diff --check`。
- B · 接入 `SKTestSession` 串行购买/恢复/退款测试；验证 verified 购买后立即新增第 4 把。仅实测证实时修 EntitlementService 衔接；不得借用本地 snapshot 放行。
- C · iPhone/iPad 模拟器、原生 Mac 与 Catalyst 编译和相关 UI 测试；可用真机再跑真实 Sandbox 路径。保留原冻结认证回归，至少跑受影响套件和完整单元测试。
- D · 单 AI 按用户最新明确指令独立做两遍检查：第一遍测试/静态范围核对，第二遍停写后按最终 diff、保护 refs、真实测试产物重新核对。此例外**不冒充 MAIC-1.3.1 的另一角色独立验收**。只有自动闸门全通过且范围正确，才按用户本次授权精确提交推送 `v1.13.11` 开发分支并读取远端 SHA；即使推送成功，也不据此推进 `v1` 或宣称发布/真机验收完成。

## 停止与回退

- 任何修改牵涉密码/认证、CloudKit 同步、产品 ID、永久购买凭据、商店后台、用户真实数据迁移或购买语义新决定时停止该部分，先报告用户。
- 真机不可用、Sandbox 产品/账号不可用或外网失败不伪造结果；可继续纯本地测试及隔离分支工作，但发布验收保持未完成。
- 不使用 reset/force；各波以精确 diff 与提交隔离，可由独立分支提交回退。原 `v1.13.9` 脏树及 `v1.13.10` 只读快照不得修改。

方法观察：用户明确拒绝逐阶段双 AI 接力，本计划仅在 `v1.13.11` 范围内采用单执行者连续工作；这不改变仓库通用治理文件，也不把自检写成独立验收。
