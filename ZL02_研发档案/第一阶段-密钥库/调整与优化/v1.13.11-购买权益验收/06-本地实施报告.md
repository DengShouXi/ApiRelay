## 已实施

- 设置页与付费墙将权益显示分成核对中、免费、已购、暂不可核对；查询失败不再伪装成免费。商品拉取和权益查询独立；前台返回、交易更新重新核对；旧请求结果不能覆盖新请求。
- 额度显示把“无限（业务返回 `nil`）”和查询失败分开，最终新增密钥仍由 `KeyVaultService` 的 StoreKit 权威闸门决定。
- 已验签购买之后，付费墙最多自动等待约 5 秒，直到 `currentTier()` 读到商店权益才关闭。未生效时保持页面、禁止再次购买并提供重新核对/恢复购买，不把本地 snapshot 变成授权凭据。待批准时同样禁止重复发起购买；取消、未验签各有独立提示/处理。
- 新增可控权益 UI fixture、本地 `SKTestSession` 交易测试及中英文文案。Xcode 27 SDK 自带 `StoreKitTest` 头文件的弃用告警在严格警告设置下会成为错误；仅 `ApiRelayTests` target 增加对应 ObjC 头文件告警豁免，App target 的编译规则不变。
- 原工作包已存在的同步文档变化只更新版本先后依赖，不实现同步。没有移植原 `v1.13.9` 脏工作树中的购买 UI/Xcode 草稿；本分支 `project.pbxproj` 只增加上述测试 target 编译标志，未改构建号。
