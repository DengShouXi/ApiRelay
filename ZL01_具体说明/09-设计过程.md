1. 宪法定原则 → `[constitution.md](../ApiRelay/.specify/memory/constitution.md)`

### 方法 2 · 三阶段独立上架（DC-009）


| 阶段      | 商店    | 设计重心           |
| ------- | ----- | -------------- |
| Stage 1 | 1.0.0 | 密钥库；**不联网调上游** |
| Stage 2 | 2.0.0 | 用量、关系图、探活…     |
| Stage 3 | 3.0.0 | 自建中转           |


前一阶段未验收，不开始下一阶段。DC-013（V1+V2 捆发）已废止。

### 方法 3 · 小迭代写完就打分支并上传

- 规划：`plan.N` + `v0-planning/phases/P0N-save.md`

节奏：**先定规格 → Phase 实现 → 上传冻结。**

## 乙 · 具体设计

> 回答：**「立下了哪些关键设计？现在还算数吗？」**  
> 完整 FR → `[spec.md](../ApiRelay/specs/001-key-vault/spec.md)`。



### 设计 A · 产品边界

- 止于剪贴板；不内嵌聊天、不做 IDE 插件。  
- 上游提供方 vs 使用方工具，不得混称「平台」。  
- V1 完全不联网调上游。

→ `[ROADMAP.md](../ApiRelay/specs/ROADMAP.md)`、`[spec.md](../ApiRelay/specs/001-key-vault/spec.md)`

### 设计 B · 密钥与安全

- 明文：Keychain / 局部变量 / 限时剪贴板。  
- 查看与复制共用一道门闩；同步优先，门闩在应用层。  
- 去重：本机明文相等比较；末位/长度不得进同步库与未过门闩界面。  
- 回收站约 30 天。

→ 宪法、`[research.md](../ApiRelay/specs/001-key-vault/research.md)`、`key-security.mdc`

### 设计 C · 架构与不可逆选型

- `UI → Business → Data`；Swift 6；iOS 18 / macOS 15；Mac = Catalyst。  
- `com.apirelay.*`；偏好分同步组 / 本机组。  
- 内购：免费额度 + 买断；产品 ID 与家庭共享 V1 定死。

→ `[plan.md](../ApiRelay/specs/001-key-vault/plan.md)` A5、宪法、`ROADMAP`

### 设计 D · 体验与设置呈现

- 仅子页画 〉；顺序「标题　当前值　ⓘ　〉」。  
- 下一层导航推入；购买/选文件用 sheet。

→ 宪法 Platform Experience、`settings-row-chrome.mdc`

### 设计 E · 文档与仓库布局

- 给人看：`ZL01` / `ZL02` / `ZL03`；`docs/privacy.md` 与 `specs/` 不能搬。  
- `ZL01` 只文件：入口 → 东西 → 工具思路 → 开发/分支 → 本页。  
- 大素材不入库；图标权威 `ApiRelay/icon/`。

→ `[01](./01-仓库地图.md)`、`[03](./03-路径红线.md)`
