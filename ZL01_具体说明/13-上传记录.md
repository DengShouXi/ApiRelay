<h2 id="how-to-log">§1 · 怎么记</h2>

每次实际上传之后，在对应节**最末尾**加一行。各节表内按**日期升序**；同一天按分支名。

| 列 | 写什么 |
|---|---|
| 日期 | 上传当天 |
| 分支 | Git 分支名（或上架 tag 名） |
| 备注 | 一句，相当于这次 commit / 分支的中文名 |
| 解释 | 一两句，人能看懂改了什么即可 |

同一条热修线上后来又传，就再加一行，不要去改旧行把历史盖掉。  
不要抄 hash，不要把 `BRANCHES` 的英文长段贴过来。
