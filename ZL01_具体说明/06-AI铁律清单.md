<h2 id="rules-overview">§1 · 各管什么</h2>

| 文件 | 管什么 | 何时生效 |
|---|---|---|
| `project-governance.mdc` | 治理入口，只指向 `ZL00_项目总控/` | 每次 |
| `key-security.mdc` | 明文只许钥匙串 / 局部变量 / 剪贴板（自动清除默认可关，勿改回必须限时） | 每次 |
| `architecture-boundaries.mdc` | 三层依赖方向；主线程不等同步库 save | 每次 |
| `change-scope-discipline.mdc` | 一次对话只改一件事 | 每次 |
| `versioning-release.mdc` | 分支命名；听到「上传」先按 [`09` §1](./09-上传流程.md#save-changes)；`release/*` 只当 tag | 每次 |
| `implementation-closeout.mdc` | 改了代码要跑自检并回答收尾四问 | 每次 |
| `simulator-codesign.mdc` | 独立 DerivedData；模拟器签名 | 每次 |
| `simulator-console-noise.mdc` | 模拟器噪音不许当回归修 | 每次 |
| `settings-row-chrome.mdc` | 设置行 〉；ⓘ 紧贴标题（勿贴 〉）；自动锁定/剪贴板是子页不是首页步进器 | 每次 |
| `ai-dialog-log-10-11.mdc` | 用户说「更新 10」或上传时改 `10`，按 `11` 逐步改，不得凭记忆偷工 | 每次 |
| `document-types.mdc` | Info.plist 文档类型须接原地打开 | 改 Info.plist 时 |

另有 Cursor 斜杠命令 [`.cursor/commands/closeout.md`](../.cursor/commands/closeout.md)。

挡路就改对应 `.mdc`，别只在对话里争——下次仍会重读原文。  
治理冲突（资料放哪、能不能上传）先读 ZL00，不要在本页另写一套。
