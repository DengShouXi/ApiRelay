## 一、这个仓库里有什么

顶层分两类：

- **英文开头**（`ApiRelay/`、`docs/`）：机器或苹果认的路径，**不能改名**。
- **`ZL` 开头**：给人看的中文资料。`ZL` 是字母，会排在 `ApiRelay`、`docs` 后面；后面的数字决定组内顺序。

| 顶层文件夹 | 是什么 | 你会不会常进去 |
|---|---|---|
| `ZL01_具体说明/` | **你现在在这里。** 纯索引，只指路、不放正文 | 每次都从这进 |
| `ZL02_研发档案/` | 历次事故复盘与整改方案。有正文。**钉在仓库根，只改名前缀、不要再搬进别的文件夹** | 出问题时进 |
| `ZL03_原始素材/` | 本地素材架。架子（README）入库；截图/录屏/图标导出不入库 | 上架时进 |
| `ApiRelay/` | 代码、测试、规格、spec-kit。真正干活的地方 | AI 进，你少进 |
| `docs/` | 只有一个隐私政策。**苹果的网址指着它，路径动不得** | 几乎不进 |
| `README.md` | 给 GitHub 访客看的项目介绍，不是给你看的 | 不用进 |

`ZL03_原始素材/相关展示截图/` 与 `icon素材/` 来自以前顶层的 `ApiRelay_相关展览/`，
收进来是为了避免英文名插在代码旁边。说明见 [`../ZL03_原始素材/README.md`](../ZL03_原始素材/README.md)。

**注意**：`ApiRelay/` 里面还有一层 `ApiRelay/`。外面那层是工程目录，里面那层才是源码。
说「ApiRelay 文件夹」时容易混，本页一律写全路径。这是 Xcode 的惯例，不要改。

## 三、三条最容易踩的红线（摘要）

完整清单见 [`02-路径红线.md`](./02-路径红线.md)，这里只列最要命的三条。

1. **`docs/privacy.md` 的路径不能改。** 苹果那边填的隐私政策网址直接指着这个路径，
   改了就 404，已上架的 App 可能因此被下架。

2. **`ApiRelay/specs/` 不能搬。** spec-kit 工具把这个路径写死在代码里，搬了命令就跑不通。

3. **测试里不许直接写 `KeychainStore(...)`。** 必须用 `KeychainStore.makeForTests()`。
   2026-08-22 就是因为这个，测试把本机真实的主密码删了，人被锁在 App 外面。

## 四、日常怎么跑一遍自检

> **⚠️ 这个脚本现在还不存在**（截至 2026-08-22 复核，`ApiRelay/scripts/` 这个目录都还没有）。
> 它由 [`../ZL02_研发档案/重大历史问题/第一次-测试删除主密码/H1-验证地基.md`](../ZL02_研发档案/重大历史问题/第一次-测试删除主密码/H1-验证地基.md)
> 负责创建，**H1 还没执行**。下面写的是它建成之后怎么用。

```bash
bash ApiRelay/scripts/selfcheck.sh
```

一条命令，输出一页报告：有没有踩红线、哪些文件太大、哪些错误被吞掉、
哪些接口定了没用起来。

> 想要这个能力，就去执行 H1。**别让这一节的存在给你「已经有自检了」的错觉**——
> 这正是研发档案自己警告过的老毛病：方案写得很清楚，但没人回头对账。
