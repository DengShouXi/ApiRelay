<h2 id="maintenance">§6 · 维护约定</h2>

- 新增本目录文档：按「引入 → 有什么 → 准则 → 三条流程 → 格式 → 对话记录 → 上传记录」插入编号，并更新本页 [§1](#reading-order)、[§5](#file-list)；版式认 [`12`](./12-通用格式要求.md)。新页目录正上方必须能返回本页。
- 一段对话做完或停在一半：在 [`10`](./10-AI对话相关记录.md) 按 [`11`](./11-AI对话相关格式要求.md) 补。
- 改 `10` 的标题/编号规矩：先改 [`11`](./11-AI对话相关格式要求.md)，再改 `10`。
- 改各页共用的序号 / 标题词 / 层次 / 链接：先改 [`12`](./12-通用格式要求.md)。
- 每次说「上传」：按 [`09` §1](./09-上传流程.md#save-changes) 整段执行（对照、同步本夹、再 git）；不要只 push。`BRANCHES.md` 与 [`13`](./13-上传记录.md) 是第三步的一部分。
- 新增顶层 `ZL` 文件夹：更新 [`01`](./01-仓库地图.md) 与 [§1](#reading-order) 顶层简表。
- 路径红线有新发现：写进 [`03`](./03-路径红线.md)。
