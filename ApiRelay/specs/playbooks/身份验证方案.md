## 用户能选的三行

| 设置项 | 用户选择 | 同步 |
|---|---|---|
| **验证方式** | 四档之一 | 同步档位，不同步设备密码 / 应用密码 |
| **自动锁定** | 关，或离开多久后锁 | 同步 |
| **取用验证** | 查看、复制明文要不要验 | 同步 |

验证方式决定**怎么验**。后两行只决定这两种场合**用不用**。编辑、回收站、备份、永久删除、清空不另开开关，按下表固定规则。

## 四档

1. **不验证** — 不弹身份。自动锁定、取用验证的开关仍保存，此时暂停（设置显示「已开启，当前不生效」，不置灰）。选此档时提示：他人拿到已解锁设备可查看、复制、修改或导出；永久删除和清空仍要再次确认。
2. **设备验证**（设备验证档，出厂默认，列表标「推荐」）— 系统设备主人认证。列表标题固定用这一产品名，不随硬件改成「面容 ID / 触控 ID」。ⓘ 与系统弹窗仍用官方译名说明本机实际是面容 ID、触控 ID，或设备 / Mac 登录密码。App 不读设备密码。取消则操作终止。无生物能力时仍可用设备密码。
3. **应用密码** — 仅应用内密码，不弹系统设备密码。校验材料本机、不同步。一点该档就进入**同一**应用密码页并绑定该档，已设也进；进入页面本身不切档。未设则走准备流程，设成功并复查后才勾上；已设可「保留现有密码并继续使用此验证方式」，不强迫改密。取消保持原档。忘记则经显式确认与设备主人重置，只影响本机，落到设备验证。
4. **设备验证或应用验证** — 系统路径只启动一次 `deviceOwnerAuthentication`：系统先使用本机生物识别，失败、锁定、不可用或用户点「使用设备密码」后在同一系统流程直接进入设备密码（Mac 为登录密码），不得返回 App 后新建第二个系统认证导致再次面容/指纹。界面另提供「使用应用密码」校验**已配置**密码；系统取消不得自动改走应用密码。选中该档同样进入上述同一应用密码页，目标仍是组合档，不得改写成应用密码档。未设则立即准备；已设可保留密码继续。缺材料时系统设备验证仍可用；应用密码路径拒绝，改走独立管理或恢复，不得在解锁/取用/删除时新建密码。

旧数据：`biometricOnly` → 设备验证；`masterPassword` → 应用密码；`biometricOrPasscode` → 设备验证。

设备主人能完成显式恢复，因此知道设备密码的人也能重置应用密码。应用密码是本机门闩，不是把整个密钥库再加密一遍。

## 不验证时

冷启动与再进都直接进列表；无锁屏、无解锁钮。查看复制直接做。编辑、恢复、移入回收站、备份导入导出直接走（移入回收站可留普通「确定？」）。永久删除与清空只留不可关的破坏性确认。

## 其他操作

| 操作 | 不验证 | 其他档 |
|---|---|---|
| 新增密钥 | 直接进入 | 直接进入 |
| 编辑密钥或账号 | 直接进入 | 当前验证方式 |
| 移入回收站 | 普通确认 | 当前验证方式 |
| 从回收站恢复 | 直接恢复 | 当前验证方式 |
| 备份导入 / 导出 | 直接进入 | 进入或生成前验证 |
| 永久删除 / 清空全部数据 | 必须破坏性确认 | 先破坏性确认，再当前验证方式 |

批量只验一次。备份文件口令 ≠ 应用密码。  
**管理类凭证**（查看/配置上游管理员钥匙）：**始终设备主人**，不跟「不验证」。后台刷新读管理凭证仍不弹。

## 取用验证

开启且验证方式不是不验证时：查看、复制要验。同一详情内看完立刻复制不二弹。关详情、换密钥、离开前台、自动锁定触发后，授权失效。不得拿来导出、删除、清空。

## 自动锁定

开启且验证方式不是不验证：冷启动与真正离开超时后要解锁，用当前验证方式。控制中心、系统授权、本 App 多窗不当离开（沿用 13.7）。不验证时不上锁，开关与时长保留。

## 改设置

- 加强（从不验证到其他、开自动锁、缩短时长、开取用）直接写。
- 降低须用**当前**验证方式先确认；persist 失败界面不降。
- 选中应用密码或组合档：都进同一应用密码页。未设则当前方式（若需要）→ 设备主人 → 新密码确认 → 写入复查 → 再保存目标。已设则显示已设置、修改、恢复及「保留现有密码并继续」；继续时验证当前方式后保存目标，不强迫改密。进入页面本身不切档。取消或任一步失败不切档。Keychain 已写但档位没存上：提示「密码已设置，验证方式未切换」，允许重试，不删刚写的材料。
- 忘记或缺材料：用户显式点恢复，设备主人确认后落到设备验证，不落到不验证，不删密钥。恢复丢掉原来那次待办，不自动做完刚才的查看或删除。选档页与锁屏的恢复始终可达，不依赖设置首页是否显示应用密码行。

## 应用密码行

设置首页仅在当前已成功保存为「应用密码」或「设备验证或应用验证」时显示「应用密码」行。待选目标、打开表单、本机已有材料都不得提前显示。切到「设备验证」或「不验证」则隐藏该行，不删材料；再选回来且材料仍在则进入已设管理，不再当首次设密。状态只看本机材料：已设置 / 未设置 / 读取失败（可重试）。不显示密码内容，不和备份口令混用。点进去：没有就创建（先必要当前验证 + 设备主人），有就改（先旧密码）、忘记/恢复，或保留现有密码并继续。界面称「应用密码」，不称主密码或应用主密码。
