## 用户能选的三行

| 设置项 | 用户选择 | 同步 |
|---|---|---|
| **验证方式** | 四档之一 | 同步档位，不同步设备密码 / 应用密码 |
| **自动锁定** | 关，或离开多久后锁 | 同步 |
| **取用验证** | 查看、复制明文要不要验 | 同步 |

验证方式决定**怎么验**。后两行只决定这两种场合**用不用**。编辑、回收站、备份、永久删除、清空不另开开关，按下表固定规则。

## 四档

1. **不验证** — 不弹身份。自动锁定、取用验证的开关仍保存，此时暂停（设置显示「已开启，当前不生效」，不置灰）。选此档时提示：他人拿到已解锁设备可查看、复制、修改或导出；永久删除和清空仍要再次确认。
2. **设备验证**（出厂默认，列表标「推荐」）— 系统设备主人认证。名称随本机：面容 ID 或设备密码 / 触控 ID 或设备密码 / 仅设备或 Mac 登录密码。App 不读设备密码。取消则操作终止。
3. **应用密码** — 仅应用内密码，不弹系统设备密码。校验材料本机、不同步。未设则不可选。忘记则经设备主人重置，只影响本机。
4. **生物验证或应用密码** — 先面容/触控；界面提供「使用应用密码」；取消整段流程则结束，不改弹设备密码。本机未设应用密码时生物仍可用，密码入口改为先设（先过设备主人）；不得当成不验证。

旧数据：`biometricOnly` → 设备验证；`masterPassword` → 应用密码；`biometricOrPasscode` → 设备验证。

## 不验证时

冷启动与再进都直接进列表；无锁屏、无解锁钮。查看复制直接做。编辑、恢复、移入回收站、备份导入导出直接走（移入回收站可留普通「确定？」）。永久删除与清空只留不可关的破坏性确认。

## 其他操作

| 操作 | 不验证 | 其他档 |
|---|---|---|
| 新增密钥 | 直接进入 | 直接进入 |
| 编辑密钥或账号 | 直接进入 | 当前验证方式 |
| 移入回收站 | 普通确认 | 当前验证方式 |
| 从回收站恢复 | 直接恢复 | 当前验证方式 |
| 备份导入 / 导出 | 直接进入 | 进入或生成前验证 |
| 永久删除 / 清空全部数据 | 必须破坏性确认 | 先破坏性确认，再当前验证方式 |

批量只验一次。备份文件口令 ≠ 应用密码。  
**管理类凭证**（查看/配置上游管理员钥匙）：**始终设备主人**，不跟「不验证」。后台刷新读管理凭证仍不弹。

## 取用验证

开启且验证方式不是不验证时：查看、复制要验。同一详情内看完立刻复制不二弹。关详情、换密钥、离开前台、自动锁定触发后，授权失效。不得拿来导出、删除、清空。

## 自动锁定

开启且验证方式不是不验证：冷启动与真正离开超时后要解锁，用当前验证方式。控制中心、系统授权、本 App 多窗不当离开（沿用 13.7）。不验证时不上锁，开关与时长保留。

## 改设置

加强（从不验证到其他、开自动锁、缩短时长、开取用）直接写。  
降低须用**当前**验证方式先确认；persist 失败界面不降。忘记应用密码走重置，不得因失败改成不验证。
