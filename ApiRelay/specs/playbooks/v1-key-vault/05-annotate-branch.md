# 写分支备注（英 → 中）提示词

里程碑分支推送**之前**，把下面整段复制给 Cursor。

---

请更新 `ApiRelay/specs/playbooks/BRANCHES.md`，为**当前即将推送的分支**补一段台账备注。

## 要求是否合理

我的命名是 `v{未上架=0}.{大阶段0–3}.{小修订}`。请先用两三句话确认这是否适合当前仓库；若有明显坑（例如与 GitHub 默认分支、ROADMAP 文档里旧分支名冲突），先指出再写备注。

## 备注格式（必须双语）

对目标分支 `v0.Y.Z` 新增一节，**先 English，后简体中文**：

1. **English**（2–4 句）：相对上一里程碑多了什么、刻意不含什么、什么时候该 checkout 回来看。  
2. **简体中文**（同样信息，口语清楚即可）。  
3. 表格行：tip commit（写备注时的 HEAD）、role（大阶段 + 小修订含义）。

## 同时做

- 若 `README.md` / 某 Phase 提示词仍写旧名（如 `001-key-vault`、`main`），只改**与本次分支相关**的过时引用，不顺手大重构。  
- 改完 `BRANCHES.md` 后纳入即将推送的 commit（或明确说需要我确认后再 commit）。

## 不要做

- 不要 force push  
- 不要删除远程旧里程碑分支，除非我明确要求
