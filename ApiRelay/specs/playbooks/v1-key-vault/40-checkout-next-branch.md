# 切换到大阶段 `v2`

> **历史导航，不可直接执行旧切换命令。** `v2` 已是历史存在的分支；当前目标工作树、未提交改动及分支 SHA 要实时核对。切换、拉取或建线不由本页授权，闸门见 [`ZL00/03`](../../../../ZL00_项目总控/03-关账与发布闸门.md)。

**何时用**：[`30-create-next-branch.md`](./30-create-next-branch.md) 已把 **`v2`** 推上远程。

如用户本次任务确需进入 `v2`，先只读核对工作树与分支；确认不会覆盖未提交改动、目标分支未被其他 worktree 占用后再安全切换。不要对脏树盲目 `pull`。

然后打开 Stage2 playbook：

→ [`../v2-usage-insights/00-README.md`](../v2-usage-insights/00-README.md)

当时规划的每个小迭代为 `P0N-*.md` → `P0N-save.md`；如今是否实现、建分支或推送 `v2.N`，均按具体任务与用户授权决定。
Stage1 文档与 `release/1.0.0` 热修若需要，回到 `v1` / 新 `v1.N` 热修分支，**不要**在 `v2` 上改 Stage1 上架材料职责边界。
