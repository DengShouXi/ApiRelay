# v1.10 UI 验收清单（人工）

对照 `quickstart.md` §1 / §2 与 [P10-UI重设计.md](./P10-UI重设计.md)。

## 外壳（相对旧稿）

- [ ] 底部 4 Tab：按平台 / 按使用方 / 回收站 / 设置，顺序正确
- [ ] 左上「⋯」可进工具管理等次要项；回收站与设置**不**再只能从「⋯」进入
- [ ] 右上角有账号入口（可占位）；无独立登录注册流程
- [ ] 主区仍是密钥列表，不是 App Store 式大卡片墙
- [ ] My Mac / Catalyst 可编译（无裸用仅 iOS 的 List 样式）

## 主路径步数

| 路径 | 预算 | 操作要点 |
|------|------|----------|
| 录入一把密钥并出现在列表 | ≤ 5 次有意图点击 | 「按平台」Tab → + → 存账号 → 加密钥 → 存 → 列表见掩码 |
| 复制明文 | ≤ 2 次点击 + 1 次生物识别 | 行内「复制」优先 → 门闩 |
| 切双视角 | 1 次 | 底部另一个 Tab |
| 进回收站 / 设置 | 各 1 次 | 对应 Tab |

## VoiceOver / Dynamic Type

- [ ] 四个 Tab 标签可读
- [ ] 密钥行可念出名称、掩码/「本机暂无明文」、指派徽章
- [ ] 复制 / 查看可达
- [ ] 最大 Dynamic Type 下列表与底栏可用
