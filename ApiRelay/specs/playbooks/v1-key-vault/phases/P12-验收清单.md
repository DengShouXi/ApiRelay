**本文件 = 你（产品负责人）亲手验收用的操作清单。**

| **Cursor Agent（第二次）** | 仅当你把下面全部勾成 ✅ 之后：commit / push | [`P12-save.md`](./P12-save.md) |

### 正确顺序（只走这一条）

```text
1. 你把「P12-本地化验收.md」整段贴给 Cursor → Agent 实现 + 跑命令
2. Agent 汇报「代码侧做完了」→ 你打开本文件
3. 你自己做：§0 准备 → §1 英文 → §2 简中 → §3 法语回退 → §5 非回归
4. §4（命令核对）：Agent 在步骤 1 已跑过；你只需看汇报是否已通过。
   若你不放心，可自己再跑一遍脚本，但不是「必须你再验一遍命令」。
5. 全部 ✅ → 你把「P12-save.md」贴给 Cursor → Agent 才允许上传 v1.12
```

### 谁不能替谁

| 事 | 谁做 | 谁做不了 |
|----|------|----------|
| 改 macOS / iOS **系统语言** | **只有你** | Agent 改不了你电脑的系统设置 |
| 点 Tab、看文案、看布局 | **只有你** | Agent 看不到你屏幕上的真机/模拟器观感 |
| Catalog 缺口 / 源码硬编码中文 / `xcodebuild` | Agent（实现阶段） | 你不必重复当主执行人 |
| commit / push | Agent（save 提示词） | 你验收未完成前 **禁止** save |

**判定规则**：任一项与「期望」不符 → 该项打 ❌，记下界面原文（或截图），开对话让 Agent 修；**全部 ✅** 才允许执行 [`P12-save.md`](./P12-save.md)。

## 0. 检之前：统一准备（只做一次 · 你来做）

### 0.1 用哪台设备跑

任选其一（推荐顺序）：

1. **My Mac（Mac Catalyst）** — Xcode 选 scheme `ApiRelay` → destination `My Mac (Mac Catalyst)` → Run  
2. **iPhone 模拟器** — 同一 scheme，选任意 iOS 18+ 模拟器 → Run  

下面「系统语言」步骤按你选的设备做。

### 0.2 准备一份「探针数据」（避免空列表什么都看不到）

在**任意一种语言**下先建好（名称请原样使用，后面 FR-046 要用）：

| 步骤 | 操作 | 写入的名称（勿改字） |
|------|------|----------------------|
| A | 底栏/侧栏 → **按平台**（或 Platform）→ **+** → 选平台 **OpenAI** → 保存账号 | 账号名用默认即可 |
| B | 该账号下 **+** 添加密钥 | 密钥名填：`ProbeKey-不翻译` |
| C | 切到 **按使用方** → **+** 添加工具 | 工具名填：`ProbeTool-KeepName` |
| D | （可选）再加一个自定义平台账号 | 平台显示名填：`自定义探针平台` |

删掉探针可等到验收结束。

### 0.3 怎么改系统语言（方法写死）

**macOS（测 Catalyst）**

1. 打开 **系统设置 → 通用 → 语言与地区**  
2. 「首选语言」点 **+**，加入目标语言，并**拖到列表最上方**  
3. 按提示注销/重启（或至少完全退出 ApiRelay 再开）  
4. 用 Xcode 重新 Run（不要只靠热重载）

**iOS 模拟器**

1. 模拟器内：**Settings → General → Language & Region → iPhone Language**  
2. 选目标语言 → 确认重启模拟器  
3. Xcode 再 Run ApiRelay  

**三种语言都要测完**（顺序建议：English → 简体中文 → Français）。

## 4. 源码 / Catalog（主执行人 = Agent；你只核对结果）

**默认**：实现阶段 Agent 已按 [`P12-本地化验收.md`](./P12-本地化验收.md) §2 跑过；你打开 Agent 汇报，对照下表勾选即可。  
**可选**：你不信任汇报时，再自己跑下面脚本——这是抽查，不是第二套必做流程。

```bash
# 在仓库内定位到含 Localizable.xcstrings 的目录后执行
python3 - <<'PY'
import json, re
from pathlib import Path
root = Path("ApiRelay/ApiRelay")  # 按实际调整
cat = json.loads((root/"Localizable.xcstrings").read_text())
assert cat.get("sourceLanguage") == "en", cat.get("sourceLanguage")
gaps=[]
for k,v in cat["strings"].items():
    locs=v.get("localizations") or {}
    en=((locs.get("en") or {}).get("stringUnit") or {}).get("value")
    zh=((locs.get("zh-Hans") or {}).get("stringUnit") or {}).get("value")
    if not en or not zh: gaps.append(k)
print("GAPS", len(gaps), gaps[:20])
hits=[]
for p in root.rglob("*.swift"):
    for i,line in enumerate(p.read_text(errors="ignore").splitlines(),1):
        if line.strip().startswith("//") or line.strip().startswith("///"): continue
        code=re.sub(r"//.*$","",line)
        if any("\u4e00"<=c<="\u9fff" for c in code):
            hits.append(f"{p.name}:{i}")
print("CJK_HITS", len(hits), hits[:20])
info = root/"InfoPlist.xcstrings"
print("InfoPlist.xcstrings_exists", info.exists())
PY
```
