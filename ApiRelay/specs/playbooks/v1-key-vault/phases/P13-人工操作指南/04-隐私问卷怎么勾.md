# 步骤 4 · App 隐私问卷怎么勾（对照你当前 ASC 界面）

权威对照表：[`../../store-drafts/v1.13/privacy-questionnaire.md`](../../store-drafts/v1.13/privacy-questionnaire.md)  
隐私政策正文（已写好，待你 push 后可作 URL）：[`../../../../../../docs/privacy.md`](../../../../../../docs/privacy.md)

入口：左侧 **App Store → App 隐私**。

---

## 4.0 你现在这页已经对了一半

若产品页预览是 **「未收集数据」**、数据类型是 **「未从此 App 中收集数据」** → 问卷答对了，**不要**再去勾姓名/客户支持。

这页要你动手的只有两件事：

1. 填 **隐私政策网址**（现在还是 `-`）  
2. 点右上角 **发布**

---

## 4.1 具体怎么填（按按钮点）

### ① 点「隐私政策」旁边的蓝色「编辑」

不要点「数据类型」的编辑（那是改问卷用的，现在不用改）。

### ② 弹出/进入编辑后这样填

| 字段 | 填什么 |
|------|--------|
| **隐私政策网址 (URL)** | 见下方 §4.2 选一个 **https** 链接贴进去 |
| **用户隐私选择网址 (URL)（可不填）** | **留空**（本 App 无单独「隐私选择」页） |
| 语言若显示英语 (美国) | 同一 URL 即可（政策页里已含英 + 简中） |

保存/完成编辑，回到总览页。此时「隐私政策网址」不应再是 `-`。

### ③ 点右上角蓝色「发布」

把「未收集数据」营养标签正式发布到商店侧。  
**这不是**「添加以供审核 / 提交 App」，只发布隐私标签。

- [ ] 隐私政策 URL 已不是 `-`  
- [ ] 已点 **发布**  
- [ ] 预览仍是「未收集数据」  

---

## 4.2 隐私政策网址写哪一串？

仓库里已有正文：`docs/privacy.md`（英 + 简中）。

**先把该文件推到 GitHub 公开仓库**（Private 审核员打不开），然后填：

```text
https://github.com/DengShouXi/ApiRelay/blob/v1.13/docs/privacy.md
```

若你 push 的是 `main` / `v1` 而不是 `v1.13`，把路径里的分支名改成实际有这个文件的分支，例如：

```text
https://github.com/DengShouXi/ApiRelay/blob/main/docs/privacy.md
```

用手机 Safari **未登录**打开上述链接，应能看到「Privacy Policy / 隐私政策」正文。能打开再贴进 ASC。

| 不要填 | 原因 |
|--------|------|
| 只填仓库首页 `.../ApiRelay` | 不是隐私政策正文 |
| Issues 链接 | 那是技术支持网址（步骤 3 用），不是隐私政策 |
| 留 `-` 就点发布 | 常被 ASC / 审核卡住 |

技术支持网址（版本页）继续用：

```text
https://github.com/DengShouXi/ApiRelay/issues
```

与隐私政策 URL **不要填成同一个**（一个 Issues、一个 privacy.md）。

---

## 4.3 若还没 push `docs/privacy.md`

在本机仓库根目录（有 `docs/privacy.md` 的那层）提交并推送后再填 URL。  
也可先把 `docs/privacy.md` 内容贴到 GitHub Gist（Public）或任意可打开的 https 页，把该页链接填进 ASC——正文须与文件一致，勿机翻乱改。

需要我帮你 commit / push 时，在对话里明确说「提交并推送」。

---

## 4.4 第一题若曾选错

只有预览**不是**「未收集数据」时，才点 **数据类型 → 编辑**，改成「否，不会收集」，再回到 §4.1。
