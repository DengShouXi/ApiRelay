## 语言怎么配：不能全用简体中文

**不要**只填简体中文。美国 / 英国等英语区商店页会显示你配置的**英语本地化**；中国大陆商店页显示**简体中文**。


| 商店地区（用户看到的） | ASC 本地化                              | 用哪份草稿                                                                 | 本阶段要不要做             |
| ----------- | ------------------------------------ | --------------------------------------------------------------------- | ------------------- |
| **美国** 等    | **英语 (美国)** `English (U.S.)`         | `[metadata-en.md](../../store-drafts/v1.13/metadata-en.md)`           | **必做**              |
| **中国大陆**    | **简体中文**                             | `[metadata-zh-Hans.md](../../store-drafts/v1.13/metadata-zh-Hans.md)` | **必做**              |
| **英国** 等    | 可另加 **英语 (英国)**；不配时通常回退用 **英语 (美国)** | 首发可直接复用 `metadata-en.md` 全文                                           | 可选（不配也能上英国，用美式英语展示） |


说明：

1. **美国商店要用英语写**（ASC：英语 (美国)），不是简体中文。
2. **英国商店**：首发不必单独再写一套英式拼写；加「英语 (英国)」时也可整份粘贴同一份英文草稿。
3. **简体中文**只覆盖中文用户；**不能代替**英语本地化。
4. **截图**：一套英文界面图即可；中文本地化可勾「使用英语截图」或同样拖同一套（省事，本指南默认如此）。
5. **审核备注 / 联系信息**（页面底部）与语言下拉无关，全局一份即可；备注建议用英文（见 [§3.4](#sec-34)）。

## 3.2 商店文案填哪一格（先英语，再简体中文）

仍在 **iOS App 版本 1.0** 页。  
**先**把语言下拉设为 **英语 (美国)**（美国 / 多数英语区靠它；英国不配英式本地化时也会回退用它）。  
打开 `[metadata-en.md](../../store-drafts/v1.13/metadata-en.md)`，对着 ASC 标签复制：


| ASC 上的中文标签                         | 填什么（直接复制草稿）                                                                                                                                                                                                                     |
| ---------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **推广文本**                           | `Keep API keys in iCloud Keychain, assign them to tools, and copy when you need them—with optional Face ID before reveal.`                                                                                                      |
| **描述**                             | `metadata-en.md` 里 **Description** 代码块全文（从 `ApiRelay is a private vault...` 到最后一句）                                                                                                                                              |
| **关键词**                            | `API,key,vault,Keychain,OpenAI,Claude,Gemini,developer,secure,clipboard`（逗号分隔、不要空格更好；总长≤100）                                                                                                                                    |
| **技术支持网址 (URL)**                   | **必填**。可用你的公开 GitHub（苹果接受）。推荐填 Issues 页，用户好提问题：`https://github.com/DengShouXi/ApiRelay/issues`。也可填仓库首页：`https://github.com/DengShouXi/ApiRelay`。须是 **https**、未登录也能打开（仓库不要 Private）。**不是**必须另做独立官网；与「隐私政策 URL」不是同一个字段——隐私政策见步骤 4 |
| **营销网址 (URL)**                     | 可不填                                                                                                                                                                                                                             |
| **此版本的新增内容**（有的页面在下方 / What’s New） | `First App Store release: store and sync API keys, assign to tools, free tier and one-time unlock.`                                                                                                                             |


**副标题 / Subtitle**（`Secure API key vault`）有时在：

- 左侧 **综合 → App 信息**，或  
- 版本页更上方「App 信息」类字段

名称 **ApiRelay** 一般创建 App 时已定，不必改。

填完点 **保存**。

### 再贴简体中文（中国大陆商店用）

1. 语言下拉 → **简体中文**（没有就「添加本地化」）
2. 从 `[metadata-zh-Hans.md](../../store-drafts/v1.13/metadata-zh-Hans.md)` 同样贴：推广文本 / 描述 / 关键词 / 版本更新说明
3. 技术支持网址可与英语相同
4. 再 **保存**



### （可选）英语 (英国)

若要单独加 **英语 (英国)**：把 `metadata-en.md` **同一份**再贴一遍即可，不必另写英式拼写。不配也可以，英国商店会显示英语 (美国)。

## 3.4 App 审核信息（重要：对照你第二张截屏）

滚到 **「App 审核信息」**：

### 登录信息（你现在勾错了）

本产品 **没有 ApiRelay 账号 / 没有登录墙**。

1. **取消勾选「需要登录」**
2. 用户名、密码 **留空**

若 ASC 强制要说明：在下面 **备注** 里写清「无需登录」（见下）。

### 联系信息

填**你本人**真实可联：


| 字段      | 填                   |
| ------- | ------------------- |
| 姓氏 / 名字 | 你的姓、名               |
| 电话号码    | 能接到的手机（含国家码，如 +86…） |
| 电子邮件    | 你常用邮箱               |




### 备注（建议直接粘贴英文，审核员常用英文）

```text
ApiRelay has no user accounts and no sign-in. Please uncheck any sign-in requirement if shown.

How to smoke-test:
1. Launch the app — vault list appears (no login).
2. Add a fake account/key with any demo secret (do not use real API keys).
3. Copy a key — default verification is "None" (no Face ID unless changed in Settings).
4. Settings → Restore Purchases — entry must be reachable (sandbox may show nothing to restore).
5. Optional: open the profile/sync sheet for iCloud Keychain explanation.

In-App Purchase product id: com.apirelay.iap.unlimited_keys (Unlimited Keys).
Keys are stored in Keychain; secrets sync via iCloud Keychain when enabled — not via an ApiRelay server.
```

可不填。
