# 步骤 1 · 准备环境（拍之前）

目标：能在**接近上架外观**的界面里，用**假数据**截图。

---

## 1.1 打开工程

1. 用 Xcode 打开：`ApiRelay/ApiRelay.xcodeproj`  
2. 确认当前 Git 分支是 **`v1.13`**（终端：`git rev-parse --abbrev-ref HEAD`）  
3. 选 scheme：**ApiRelay**

---

## 1.2 选三个模拟器（或真机）

在 Xcode 顶部设备菜单准备好：

| 端 | 推荐设备（名称可能随 Xcode 略有不同） | 用途 |
|----|----------------------------------------|------|
| 手机 | **iPhone 16 Pro Max** 或带 **6.7″ / 6.9″** 的 Pro Max | ASC iPhone 主尺寸 |
| 平板 | **iPad Pro 13-inch**（或 12.9-inch） | ASC iPad 主尺寸 |
| 电脑 | **My Mac (Mac Catalyst)** 或 `My Mac` | ASC Mac 截图 |

没有对应模拟器：Xcode → Settings → Platforms，下载 iOS / 对应 runtime。

---

## 1.3 尽量用 Release 外观

商店图不要露出 DEBUG 专用按钮（例如付费墙里的「DEBUG: Grant Unlimited」）。

任选其一：

- **推荐**：Product → Scheme → Edit Scheme → Run → Build Configuration 选 **Release**，再 Run；或  
- 继续 Debug，但截图时**不要打开**带 DEBUG 字样的付费墙页。

---

## 1.4 造假数据（必须）

**禁止**把你自己的真实密钥贴进截图包。

建议造 2～3 把假钥：

| 字段 | 示例 |
|------|------|
| 平台 | OpenAI / Anthropic（预置即可） |
| 显示名 | `Demo OpenAI`、`Demo Claude` |
| 密钥正文 | 随便一串假字符，如 `sk-demo-not-real-0000`（截图时只显示掩码也行） |
| 使用方 | `Cursor Demo`、`Terminal Demo` |

操作路径（界面可能略有文案差异）：

1. 打开 App → 密钥列表  
2. 添加账号 / 添加密钥 → 填上表假数据  
3. 切到「按使用方」视角，指派一把假钥给 `Cursor Demo`  
4. （可选）软删一把钥，留给「回收站」截图

---

## 1.5 系统语言（本指南默认英语）

1. 模拟器菜单：**Features → Language & Region**（或系统设置 → General → Language & Region）  
2. 首选语言设为 **English**  
3. 重启 App，确认界面是英文  

以后若要补中文图：改成 **简体中文**，同一套画面再拍一遍。

---

## 1.6 截图前快速自检

- [ ] 列表里只有假数据 / 掩码  
- [ ] 看不到 DEBUG 覆盖文案  
- [ ] 设置里能看到 **Restore Purchases / 恢复购买**（Agent 已加）  
- [ ] 没有「系统级强制」「无法绕过」之类字样
