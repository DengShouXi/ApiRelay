## 先回答：要不要先 TestFlight？还是直接发布？

**先 TestFlight，不要直接点「提交以供审核」。**

| 做法 | 建议 |
|------|------|
| 模拟器 / Xcode Run | 开发够用，**不够**当上架前终检 |
| **TestFlight 真机内测** | **首发推荐必做**（步骤 6） |
| 直接送审上架 | 仅在 TestFlight 自测 OK + `10-verify` PASS 后，走 T062 授权 |

上传到 ASC 的构建可以先给 TestFlight，测完**同一构建**再送审，不浪费工。  
具体点哪里：[`06-TestFlight内测.md`](./06-TestFlight内测.md)。

---

## 先回答：手机、平板、电脑都要截吗？

**要。** 本工程同时支持：

| 设备 | 工程配置 | App Store 要不要截图 |
|------|----------|----------------------|
| **手机 iPhone** | ✅ | **必须** |
| **平板 iPad** | ✅（`TARGETED_DEVICE_FAMILY = 1,2`） | **必须** |
| **电脑 Mac** | ✅（`macosx` + Mac Catalyst） | **必须**（若你要上 Mac 商店；本产品按三端上架准备） |

每种设备 **至少 1 张**，建议各拍 **3～5 张**（最多 10 张）。  
同一设备族里，拍**最大尺寸那一档**即可，ASC 会缩小给更小机型用。

语言：界面是英语 + 简体中文。做法二选一：

1. **推荐省事**：用**英语界面**拍一套三端图，中文 ASC 复用同一套图（ASC 允许）；或  
2. 英语、简体中文各拍一套（更费时，观感更好）。

本指南默认走 **做法 1**（先英语一套三端；有余力再补中文）。

5. **禁止**在本指南任意一步点 ASC「提交以供审核」。
