## 2.1 每种设备拍哪些画面

至少拍下面 01～04；05 可选。三端**同一套画面**各拍一遍。

| 编号 | 画面 | 你怎么进 |
|------|------|----------|
| 01 | 按平台列表 | 密钥 Tab → 分组「按平台」 |
| 02 | 按使用方 | 切换到「按使用方」 |
| 03 | 设置 | 设置 Tab；露出验证 / 剪贴板，并滚到能看见 **Restore Purchases** |
| 04 | iCloud 同步说明 | 左上角账号 / 同步入口 → 说明页 |
| 05 | 回收站（可选） | 打开回收站，里面只有假删除项 |

## 2.2 手机（iPhone）怎么截

1. Xcode 选 **iPhone 16 Pro Max**（或 6.7″/6.9″）→ Run  
2. 造好假数据后，打开要拍的画面  
3. 模拟器菜单：**Device → Trigger Screenshot**（或 `⌘S`，以你 Xcode 版本菜单为准）  
4. 截图一般在桌面；检查像素大约是下列之一即可：  
   - `1290 × 2796`  
   - `1320 × 2868`  
   - `1260 × 2736`  
5. 竖屏（Portrait）  

命名示例：

```text
iphone69-en-01-by-platform.png
iphone69-en-02-by-consumer.png
iphone69-en-03-settings.png
iphone69-en-04-icloud-sync.png
iphone69-en-05-trash.png          # 可选
```

把文件拖进上面的 `screenshots/` 文件夹。

- [ ] 手机 01～04 已放入目录

## 2.3 平板（iPad）怎么截

1. Xcode 选 **iPad Pro 13-inch** → Run  
2. 同样假数据、同样 01～04 画面  
3. 同样 Trigger Screenshot  
4. 目标像素大约：  
   - `2064 × 2752`，或  
   - `2048 × 2732`  
5. 竖屏即可（与手机一致便于对比）  

命名示例：

```text
ipad13-en-01-by-platform.png
ipad13-en-02-by-consumer.png
ipad13-en-03-settings.png
ipad13-en-04-icloud-sync.png
```

- [ ] 平板 01～04 已放入目录

## 2.4 电脑（Mac / Catalyst）怎么截

1. Xcode 选 **My Mac (Mac Catalyst)** 或 **My Mac** → Run  
2. 把窗口调到舒服的大小（不要截到半个菜单栏乱裁）  
3. 截图快捷键：  
   - 窗口截图：`⇧⌘4` 再按空格，点窗口；或  
   - 菜单：**File → 截取窗口**（若有）  
4. ASC 要求 **16:10**，下列分辨率之一：  
   - `1280 × 800`  
   - `1440 × 900`  
   - `2560 × 1600`（推荐 Retina）  
   - `2880 × 1800`  
5. 若截出来不是 16:10：用预览 App 裁剪到上表任一尺寸（只裁边，不要拉伸变形）  

命名示例：

```text
mac-en-01-by-platform.png
mac-en-02-by-consumer.png
mac-en-03-settings.png
mac-en-04-icloud-sync.png
```

- [ ] 电脑 01～04 已放入目录

## 2.5 尺寸不对怎么办（最常见坑）

1. 用「预览」打开 PNG → 工具 → 调整大小，看像素  
2. **不要**随便拉变形；只裁切到官方允许的分辨率  
3. ASC 上传时报错时，以 ASC 红字提示的尺寸为准（Apple 会改表，本文件可能滞后）  

查像素的终端命令（可选）：

```bash
sips -g pixelWidth -g pixelHeight 你的文件.png
```
