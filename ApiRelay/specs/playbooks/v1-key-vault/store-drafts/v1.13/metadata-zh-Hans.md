## 描述

```text
ApiRelay 是面向开发者的 API 密钥保险库，帮你在自己的 Apple 设备上保管、整理并取用密钥。

安全存放
密钥明文保存在系统钥匙串中。账号等元数据经 iCloud 同步；明文经「iCloud 钥匙串」在你本人的 Apple 设备之间端到端加密同步——不会上传到 ApiRelay 自有服务器。

整理与指派
可按上游平台或使用方查看。把密钥指派给工具，清楚每把钥匙用在哪里。

需要时再取出
查看或复制明文前，可按设置进行身份确认（面容 ID、触控 ID、设备密码或主密码，由你选择）。复制到剪贴板的明文可在你设定的时限后自动清除。

免费与一次买断
免费档可保存有限数量的密钥；一次买断后解锁无限密钥。设置中始终提供「恢复购买」。

隐私优先
无需 ApiRelay 账号，无分析 SDK。应用只负责保管与分发密钥，不会把你的 API 调用发到我们的服务器。

若要在多台设备共用同一密钥明文，请在每台设备开启 iCloud 钥匙串。
```
