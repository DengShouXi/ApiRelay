# 分支与版本

**用途**：分支怎么命名、各分支 tip / 时间 / 主要做了什么、如何避免搞混旧名。

**权威文件（请在这里阅读与修改）**：[`../BRANCHES.md`](../BRANCHES.md)

**返回索引**：[`索引.md`](./索引.md)

## 现行命名（记这套即可）

| 种类 | 写法 | 例子 |
|------|------|------|
| 规划小迭代 | `plan.N` | `plan.1` |
| 规划 tip | `plan` | `plan` |
| 产品大阶段 tip | `v1` / `v2` / `v3` | `v1` |
| 产品小迭代 | `v{阶段}.{小迭代}` | `v1.12` |
| 上架 tag（仅商店） | `release/N.0.0` | `release/1.0.0` |

旧名 `v0.0.*` / `v0.1.*` 等已废弃，远程应已清理；勿再建。
