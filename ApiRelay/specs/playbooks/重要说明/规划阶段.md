# 规划阶段（plan）

**用途**：规格与规划线工作；对应 Git 分支 `plan` / `plan.N`。

**权威目录**：[`../v0-planning/`](../v0-planning/)  
**建议起步**：[`../v0-planning/00-README.md`](../v0-planning/00-README.md)

**返回索引**：[`索引.md`](./索引.md)

## 怎么用

1. 打开 `00-README.md` 看本阶段入口。  
2. 在 `phases/` 里找 `P0N-某某.md` 写/实现。  
3. 写完后按 `P0N-save.md`：更新台账 → commit → push 到 `plan.N`。

改阶段范围请去 [`../../ROADMAP.md`](../../ROADMAP.md)；改分支规则请去 [`../BRANCHES.md`](../BRANCHES.md)。
