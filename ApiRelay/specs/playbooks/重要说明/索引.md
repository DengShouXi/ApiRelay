## 硬规则（摘要）

- 小阶段写完 → 打对应分支并上传（`plan.N` / `v1.N` / `v2.N` / `v3.N`）。  
- 已关账 / 已上架后的修 bug → 对 Cursor 说「上传」（[`09` §1](../../../../ZL01_具体说明/09-上传流程.md#save-changes)），git 走 [`../热修-save.md`](../热修-save.md)（例：`v1.13.1`），**不要**盖冻结 tip，**不要**开 `release/*` 分支。  
- **禁止**再新建旧名 `v0.0.*` / `v0.1.*` / `v0.2.*` / `v0.3.*`。  
- 改分支规则只改 `BRANCHES.md`；改阶段范围只改 `specs/ROADMAP.md`。  
- **不要**在本目录复制一整份 BRANCHES / ROADMAP。  
- Stage1 商店材料在 **P13**；发布动作在 **T062**（`12-release-T062.md`），二者不要混做。
