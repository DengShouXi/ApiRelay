# 压力测试样本

方法版本：MAIC-1.3

1. 原主工作树与本分支同时修改 `project.pbxproj`/scheme：只接受隔离 worktree 差异，不自动合并。
2. UI 测试标志误用 `AppRuntime.isRunningTests`：必须失败，因为这会关闭真实生命周期观察并产生假通过。
3. 设置保存失败：UI 必须显示旧权威值，不能先显示成功状态。
4. 迟到认证回调：request scope 失效后不得切换策略、解锁或提交业务操作。
5. Home 快返与控制中心往返：前者立即锁，后者不误锁；测试不使用固定 sleep 冒充确定性。
6. 机械拆文件后：类型、访问控制、actor 隔离、await/commit 顺序与用户文案必须等价。
7. 任一敏感标识、schema/store path 或本地化文案变化：阻塞验收。

方法观察：未发现需要迭代的方法问题。
