# 自动化架构与验收口径

方法版本：MAIC-1.3

## 自动化层次

- 单元/characterization：固定认证、锁定、遮挡、偏好提交、剪贴板、WAL 与 gate 语义。
- XCUITest：覆盖真实导航、弹框挂载、选中态、首帧锁屏、Home 快返和失败回滚；只用固定 DEBUG fixture。
- 三平台：iOS 模拟器、原生 macOS、Mac Catalyst 分别构建/测试并保存新结果。
- 人工边界：Face ID/Touch ID/设备密码系统面板、真实 App Switcher、Cmd-Tab、多窗口、Universal Clipboard 仍需真机/本机验证。

## 通过标准

1. 原有测试全绿，新增 UI 测试含实质断言，不是空启动。
2. 不复用会关闭生命周期监听的 unit-test runtime 标志。
3. 敏感标识基线无漂移，生产数据路径无变化。
4. 拆分后的公共 façade/protocol、actor 和提交顺序等价。
5. 实际重复状态被移除；本来就是单一权威的 coordinator/gate/clipboard 不做负向重写。
6. 自检、`git diff --check`、范围检查和独立审计通过。

方法观察：未发现需要迭代的方法问题。
