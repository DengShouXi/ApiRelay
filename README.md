# ApiRelay

面向 Apple 设备的 API 密钥保险库：在 iPhone 与 Mac 上保管、整理并取用密钥，不把明文交给自有服务器。

密钥散落在备忘录和聊天记录里、同一把钥匙贴进多个工具，是常见痛点。当前可交付的主流程是：登记上游账号 → 把密钥指派给使用方工具 → 经身份确认后复制到系统剪贴板。产品止于剪贴板，不集成 VS Code / Cursor 等外部工具，也不做 App 内聊天。

明文存在系统钥匙串，经 iCloud 钥匙串在本人设备间同步。查看与复制共用一道门闩（面容 ID、触控 ID、设备密码或主密码，可关）。剪贴板明文可限时自动清除。

## 阶段（摘要）

功能范围以规格为准，这里只作导航。当前实现的是 Stage 1；用量、探活、中转尚未作为已交付能力。

| 阶段 | 做什么 | 商店版本 |
|------|--------|----------|
| Stage 1 | 保管、指派、双视角、免费额度与买断 | 1.0.0 |
| Stage 2 | 用量看板、关系图、可用性检测 | 2.0.0 |
| Stage 3 | 自建中转（下游配置不用随上游密钥改） | 3.0.0 |
